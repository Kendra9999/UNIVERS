### Install
```

conda activate UNIVERS
pip install -r requirements.txt
git clone https://github.com/Kendra9999/UNIVERS.git
```


### Data preparation

Our method uses synthetic data generated by [Anatomix](https://github.com/neel-dey/anatomix/). Please follow the data generation pipeline in [anatomix/synthetic-data-generation](https://github.com/neel-dey/anatomix/tree/main/synthetic-data-generation) to synthesize pseudo training data. 

The synthetic data structure are as follows:
```
├── synthetic_data/  
│   ├── label_ensembles/
│       ├── {idx}.nii.gz             # The label map file for case idx.
│       └── ...
│   ├── synthesized_views/
│       ├── view1/
│           ├── view1_{idx}.nii.gz   # The image file 1 for case idx.
│           └── ...
│       ├── view2/
│           ├── view2_{idx}.nii.gz   # The image file 2 for case idx.
│           └── ...
|
```



### Training
We use WANDB to log the training process. Please log in your WANDB account and write your entity name in `UNIVERS/configs/univers/univers.py`.

Please write your synthetic data directory path in `UNIVERS/configs/univers/univers.py`.

Please run the following command to train the model:
```
cd UNIVERS/tools
CUDA_VISIBLE_DEVICES=0 python train.py configs/samv2/samv2.py --auto-resume --no-validate
```

### Inference

#### Demo for one-shot landmark detection
Prepare two image files, and run the following command for one-shot landmark detection:
```
cd UNIVERS/downstream/landmark_detect

# By nearest-neighbor matching
python demo.py \
  --checkpoint /path/to/checkpoint.pth \
  --img1-file /path/to/img1-file.nii.gz \
  --img2-file /path/to/img2-file.nii.gz \
  --query-point query_point_coordinate

# By fixed-point-based matching
python demo_stable_points.py \
  --checkpoint /path/to/checkpoint.pth \
  --img1-file /path/to/img1-file.nii.gz \
  --img2-file /path/to/img2-file.nii.gz \
  --query-point query_point_coordinate
```
Note that the above demo files are for CT images. If you use MR images, please modify the intensity preprocessing code in the loading function.

#### Evaluate in the Deep Longitudinal Study (DLS) dataset
Please follow the instruction in [DLT](https://github.com/JimmyCai91/DLT/) to download the test images and the ground truth json files.

Run the following command for evaluation:
```
cd UNIVERS/downstream/landmark_detect

python test_dlt_stable.py \
  --checkpoint /path/to/checkpoint.pth \
  --data-path /path/to/test/image/dir/ \
  --anno-path /path/to/test/annotation/dir/ \
```
